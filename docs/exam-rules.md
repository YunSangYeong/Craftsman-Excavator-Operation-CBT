# 시험 규칙 확인 상태

확인 시도일: 2026-10-21 (한국 시간). 대상: 굴착기운전기능사 필기.

공식 확인 대상으로 삼은 종목 페이지:
https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=7862

이 환경의 요청 결과는 `curl: (56) CONNECT tunnel failed, response 403`, HTTP 응답 코드는 `000`이었다. Q-Net 서버의 본문을 읽은 결과가 아니며 네트워크 프록시에서 차단되었다. 출제기준 첨부파일·시행 공고·기출 원문·정답·재배포 조건은 열람하지 못했다. URL의 종목 식별자도 이번 공식 본문으로 재검증하지 못했다. 공식 자료를 읽은 것처럼 인용하지 않는다.

| --- | --- | --- |
| 과목 | 굴착기 조종, 점검 및 안전관리 (통합 1과목) | 미완료 |

숫자가 원본 전기기능사 앱과 같다는 이유로 검증 완료 처리하지 않았다. `src/qualification.json`의 `verification.status`는 `pending`이며 화면의 문제은행 관리에서 학습용 가정과 확인 한계를 표시한다. 공식 모의시험·실제 출제 비중 재현을 주장하지 않는다. 외부 자료 확인 후 설정을 변경할 때는 채점 경계·문항 수·복원 테스트도 함께 조정해야 한다.

기출은 공개 열람 가능 여부와 원문·이미지·정답의 재배포 허용 여부를 별도로 확인해야 한다. 현재 외부 기출·복원 자료는 등록하지 않았다. 자체 제작 72문항에 공식 출제 연도나 회차를 부여하지 않았다.
