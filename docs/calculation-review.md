# 추가 계산형 928문항: 유형·단위·가정 검토

2026-10-22 한국 시간. 32개 계산 틀 × 각각 29개 서로 다른 입력 조건. 원문 기출·복원 아님. 출처는 AI 일반 지식의 기본 물리식과 단위 정의이며 외부 교재·공식 문서를 읽었다고 주장하지 않는다. 아래 식은 이 작업에서 검토한 모델을 직접 설명한 것이며 외부 전문가 인증은 아니다.

## 검토와 독립 수치 검사

- 작성: Python `Decimal`, 정밀도 36, 최종값을 소수 둘째 자리까지 ROUND_HALF_UP. 운반 횟수만 ROUND_CEILING의 정수 올림. π가 필요한 식에는 본문에서 **π=3.14**를 명시하며 중력가속도는 모멘트 문항에서 **9.8 m/s²**로 명시한다.
- 문장·가정: 같은 AI 작업 내 유형별 자기 검토. 각 유형의 단위, 대상 물리량, 이론값/실제값과 효율 적용, 상태·경계 조건, 정답·해설 일치를 검토했다. 928개 모든 문장에 대한 독립 인간 검수나 외부 전문가 검수는 아니다.
- 계산: TypeScript 테스트는 Python 생성 함수를 읽어 실행하지 않고 별도로 SI( Pa, m², m³/s, W, N 등)에서 환산한다. 928세트 모두 재계산·정답 번호·네 보기의 수치/단위·정답 유일성·해설 결과·반올림 지시·입력 본문 표시를 검사한다.
- 보기: 정답 수치를 기준으로 잘못된 산술 결과를 세 개 만든다. 실제 수험자 오개념 연구로 검증된 오답은 아니다. 동일 단위·표시 정밀도로 비교하며 다른 보기가 정답과 동치가 되지 않게 한다.
- 중복: 고유 ID와 본문 및 정렬된 보기를 정규화하여 검사한다. 같은 틀의 다른 숫자 조건은 family로 묶어 변형임을 공개한다. 임의 시드 없이 순서·ID·수치가 재생성되며 기존 72개 데이터는 고정 SHA 테스트로 보존한다.
- 출제: 모의시험에서는 72개 개념 문항과 32개 계산 family를 각각 하나의 추출 그룹으로 취급해 family를 우선 한 번만 뽑는다. 현재 104그룹으로 60문항을 만들 수 있어 family 반복 보충이 필요 없다. 랜덤은 전체 1,000개 ID를 순회하므로 계산형 비중이 높다. 가져오기 데이터로 그룹 수가 부족해진 경우 기존 고유 ID 보충 정책은 유지한다.

## 안전·적용 범위

유압 힘·축 토크·정적 모멘트는 실제 버킷 굴착력이나 허용 인양하중이 아니다. 효율은 본문의 종류(체적/기계/전체)에만 적용한다. 실린더 후퇴는 로드 면적을 빼고, 모터 체적효율은 실제 회전수에 곱한다. 배기량은 지름의 제곱과 행정으로 계산하고 틈새 체적은 제외한다. 연료 예비량·토량 계수·밀도·채움률·속도는 주어진 연습 조건이며 법정 값이나 보편적인 현장 기준이 아니다.

토량의 자연상태/흐트러진 상태를 구별하고 차량 계산은 중량 한도를 별도로 충족한 체적 모형이다. 접지압은 양 트랙 총면적을 사용한 균등 정적 평균이며 지반 안전 판정이 아니다. 경사율은 각도와 다르고 분모는 수평거리다. 축전지 Wh는 명목값이고 실제 사용 가능한 에너지와 다르다. 전압강하의 R은 왕복 전체 저항으로 두 배 보정하지 않는다.
