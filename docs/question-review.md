## 작성 근거와 이용 조건

AI의 일반적인 기계·유압·현장 안전 지식을 바탕으로 이 작업에서 새로 작성했다. 전기기능사 원본 900문항, 민간 CBT 사이트, 읽지 않은 교재나 공식 출제기준을 출처로 삼지 않았다. `sourceUrl`의 저장소 링크는 작성·검토 기록을 가리키며 외부 정답 증명이 아니다. 원고는 `scripts/build-bank.py`, 기본 데이터는 `src/data/questions.json`이다. 생성 시드는 없으며 명시적 원고 순서와 고정 ID, 순환 보기 순서로 결정적으로 직렬화한다.

새 문제 원고와 데이터는 CC BY 4.0으로 제공한다. 표시: Craftsman-Excavator-Operation-CBT contributors, 이 저장소 링크 및 변경 사실. 재사용 앱 코드는 electrician-cbt contributors의 MIT 고지를 보존했다. 제3자 가져오기 자료에는 해당 자료의 권리 조건이 별도로 적용된다. 공공 자료를 자유 재배포할 수 있다고 추정하지 않았다.

## 검토 범위와 한계

내부 검토: 각 문장의 범위, 한 개 정답, 보기 간 구별, 해설과 정답의 일치, 보편적인 안전 원칙에 반하는 답안 여부를 이 작업에서 검토했다. 특정 제조사의 운전 절차를 일반화하지 않도록 제조사 지침을 우선하며, 전선 이격·경사각 등 확인되지 않은 법정 수치와 연도·회차는 넣지 않았다. 반복되는 정지·격리 원칙은 서로 다른 고장·위험 상황을 묻지만 개념적으로 겹치는 부분이 있다. 72문항을 72개 독립 이론이나 실제 출제 유형으로 주장하지 않는다.

ID 및 NFKC·공백 정규화 본문과 정렬된 보기의 정확 중복은 0건이다. 의미상 검토에서도 같은 질문을 보기만 바꿔 수량으로 늘리지 않았으나 유사 개념의 중복성 판단에는 한계가 있다. 제외 중복 0, 검증 대기 0, 기본 은행 내부 검토 상태 72. `reviewed`는 이 내부 검토만을 의미하며 전문가 인증이 아니다.

**외부 전문가 검수, 공식 출제기준 대조, 현장 실장비 검증은 수행하지 않았다.** 문항 내용은 장비별 운전·정비 매뉴얼을 대체하지 않는다. 계산형이 없으므로 독립 계산 재검산은 해당 없음이다. 자동 구조 테스트를 개념 정답의 외부 검증으로 표현하지 않는다. 검증 대기 가져오기 문항은 학습에서 제외되며 사용자 로컬 승인분은 공용 기본 72문항이나 목표 수에 합산하지 않는다.

1,000문항을 확보·검토하지 못한 이유는 검증된 외부 원문·재배포 권한과 전문가 검토 자료가 없는 상태에서 무관한 문제나 단순 변형으로 수량을 채우지 않았기 때문이다. 최소 한 회 60문항 실행이 가능하다는 사실이 1,000문항 기준을 대체하지 않는다.
