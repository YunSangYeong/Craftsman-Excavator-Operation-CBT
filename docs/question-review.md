# 문제은행 출처와 내부 검토 기록

**기본 등록 1,000문항 / 부족 0문항.** 원문 기출 0 · 복원 0 · 자체 제작 1,000.
구성은 기존 개념형 72문항과 **계산 조건 변형 928문항 = 32유형 × 각 29조건**이다. 변형 928개는 928개 독립 개념 또는 기출이 아니다.

## 출처·이용 조건

기존 72문항은 최초 커밋 `2b55115`의 ID·본문·보기·정답·해설·메타데이터를 모두 보존했다. `scripts/build-bank.py`에 기존 원고를 유지하고 추가 계산형은 `scripts/numeric_bank.py`에 별도로 작성했다. 기본 JSON은 `src/data/questions.json`이다. 생성 시드는 없으며 명시적 입력 순서와 고정 ID·보기 회전으로 재현한다.

추가 원고도 AI 일반 지식의 기초 물리식·단위 정의에 근거한 자체 제작이다. 민간 사이트나 전기기능사 원본 문제를 복사하지 않았고, 열람하지 않은 공식 자료·교재를 출처로 제시하지 않았다. `sourceUrl`의 저장소 링크는 작성·검토 기록이며 외부 정답 증빙이 아니다. 모든 연도·회차는 null이다. 자체 원고와 데이터는 CC BY 4.0이며 표시는 Craftsman-Excavator-Operation-CBT contributors, 이 저장소 링크와 변경 사실이다. 앱 MIT 고지 및 제3자 자료의 별도 권리는 유지한다.

## 내부 검토 범위

같은 AI 작업에서 원고 작성과 유형별 자기 검토를 수행했다. 계산 32유형의 단위·가정·질문·정답·해설 일치를 검토하고, 각 29세트 전부를 생성 Python 코드와 별도 작성한 TypeScript SI 단위 계산 경로로 재계산했다. 정답 번호, 유일한 정답 수치, 동일 단위 보기, 반올림, 올림 처리, 해설 결과 포함 및 입력이 본문에 실재하는지도 테스트한다. 상세 식·전제는 [계산형 검토 기록](calculation-review.md)에 있다.

고정 문장 틀의 928개 모든 해설을 사람이 한 줄씩 별도로 읽은 검수가 아니다. 계산 테스트는 수치·단위 검증이고, 유형별 문장 자기 검토는 개념·가정 검토이며 서로 구분한다. **외부 전문가 검수·공식 출제기준 대조·실장비 검증은 미완료**다. `reviewed`는 이 내부 범위를 뜻하며 외부 인증이 아니다. 공식 과목 분포 재현이나 실제 출제 빈도를 주장하지 않는다.

정규화 본문, ID, 정렬된 보기 포함 지문 중복은 0건이고, 같은 family 내 숫자 조건 차이는 의도한 변형으로 명시했다. 32개 계산 틀에도 힘·압력·일·동력 등 개념상 연관이 있다. 이를 32개 독립 물리 법칙이나 1,000개 독립 개념으로 부풀리지 않는다. 기존 개념형의 반복 안전 원칙도 문맥별 질문으로 유지했다. 사용자 로컬 승인분과 검증 대기는 기본 1,000개에 포함하지 않는다.

수치조건은 장비 정격·법정 한도·허용 주행속도·실제 인양 가능량이 아니다. 안전거리·경사 허용각·매뉴얼별 정비 수치를 만들지 않았다. 계산에서는 누설·마찰·효율·토질 상태 등 필요한 단순화 조건을 본문에 명시한다. 장비와 현장 운용은 제조사 자료·작업계획·법규 확인을 별도로 해야 한다.
